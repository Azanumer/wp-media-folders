# WP Media Folders

Organize the WordPress Media Library into folders — no more scrolling through thousands of ungrouped uploads to find one image.

## Features

- **Folder taxonomy** — a hierarchical `Media Folder` taxonomy for attachments, managed under **Media → Media Folders** (nested folders supported).
- **List filter** — a folder dropdown on the Media Library screen, including an **Unassigned** option that shows only files with no folder.
- **Folder column** — each row shows its folder, linked to the filtered view.
- **Bulk move** — select files and use the bulk actions menu to move them into a folder, or remove them from folders.
- **Attachment screen** — set the folder right on the attachment edit screen.
- **Media modal** — the folder filter also applies to the media picker used inside the editor, so you can find images by folder while writing.
- **No file moves** — folders are taxonomy terms, not directories on disk, so existing URLs never break.

## Installation

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it from **Plugins**.
3. Create folders under **Media → Media Folders**, then assign files from the Media Library.

## Uninstall

Deleting the plugin removes all folder terms. Your media files and their URLs are untouched.
